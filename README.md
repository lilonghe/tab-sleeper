# 标签休眠 · Tab Sleeper

一个轻量的 Chrome / Edge 扩展：非激活标签页闲置指定时间后自动休眠，释放内存。

## 功能

- 默认闲置 **5 分钟** 后自动休眠，可在设置中调整为 1–240 分钟
- 每分钟检查一次，比浏览器自带的休眠策略响应更快
- 默认跳过固定标签和正在发声的标签
- 弹窗内可随时暂停、查看休眠数量、立即执行一次检查
- 休眠后的标签仍保留在标签栏，点击时自动重新加载

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录

## 说明

- 浏览器内部页面（`chrome://`、扩展页等）不会被休眠
- 休眠会卸载页面，未提交的表单内容可能丢失；这也是浏览器自带休眠的既有行为
- 扩展只使用 `tabs`、`alarms`、`storage` 三个权限：读取标签状态、定时检查、保存设置

## 目录

```text
tab-sleeper/
├── manifest.json    # 扩展清单
├── background.js    # 活跃时间记录与休眠扫描
├── popup.html/js    # 弹窗
├── options.html/js  # 设置页
├── ui.css           # 弹窗与设置页共用样式
└── icons/           # 扩展图标
```
